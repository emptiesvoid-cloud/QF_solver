# Code of Conduct

QF_solver contributors are expected to be respectful, factual and open to
technical challenge. Discuss numerical evidence, assumptions and limitations
without personal attacks or pressure to overstate maturity.

Unacceptable behavior includes harassment, discrimination, disclosure of
private data, knowingly falsifying verification evidence, and presenting an
experimental result as validated.

Report concerns privately through the security contact described in
`SECURITY.md`. The project owner decides proportionate corrective action,
including removal of content or contribution access.
