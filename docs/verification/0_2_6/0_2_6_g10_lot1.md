## Code-path audit

The audited routes use the following existing paths:

- `NonlinearStaticSolver` provides the common load-control Newton driver,
  material-state transactions, adaptive stepping, and the arc-length mixin.
- `GeometricNonlinearStaticSolver` uses the existing Total-Lagrangian assembly,
  Green-Lagrange kinematics, and the common Full Newton driver.
- `CompositeNonlinearAssembly` composes material, geometric, and contact
  contributions under the common residual/tangent infrastructure.
- The current finite-kinematic material route uses Green-Lagrange strain and
  second Piola stress. Its own documentation does not claim general finite-
  strain plasticity.
- Contact composition remains frictionless and bounded by the existing G09
  contract. No new contact formulation is audited or proposed.
- The checkpoint, rollback, convergence, finite-value, and typed failure paths
  are covered by the existing targeted contracts listed in the JSON matrix.

No real bug was identified in this lot. The targeted evidence did not show a
new NaN/Inf path, silent convergence, determinism failure, or numerical source
regression.

## External evidence boundary

No new external run was performed in Lot 1. Existing G06 and G09 evidence is
retained only where its documented scope is compatible. It does not establish:

- external validation of finite-kinematic J2;
- external validation of J2 plus geometric nonlinearity;
- external validation of geometry plus contact as an equivalent formulation;
- external validation of triple coupling; or
- physical branch-selection validation for arc-length continuation.

Those gaps remain explicit closeout blockers if any of those routes are later
proposed for a stronger maturity claim. An external tool or deck that is not
formulation-compatible must remain skipped or bounded, never promoted to PASS.
