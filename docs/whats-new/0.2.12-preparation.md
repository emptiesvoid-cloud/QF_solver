# 0.2.12 preparation note (unreleased)

This is an internal integration-candidate note, not a release announcement.

The B* work-conjugate tangential transfer is recorded as an
`EXPERIMENTAL_BOUNDED` sub-capability for linear-static frictional contact on
one initially frozen slave/master pair and one reference master triangle,
under analyst-enforced small rotations. It remains explicitly opt-in; legacy
transfer remains the default. The [worked fixture](../../examples/contact/frictional_bstar_small_rotation/README.md)
requires an explicit `--run` to launch FEM.

R13/R14 provide exploratory algebraic and stick/slip evidence. The integrated
R16 output was replayed offline in R17/R18; the original R16 pytest FAIL is
preserved. This evidence does not qualify finite sliding, large rotations,
multiple contact, a global consistent slip tangent, general spatial
convergence, or industrial/production use. No numerical angle threshold is
implemented. No public release or certificate is implied.
