# What's New in QF Solver 0.2.10

**Status:** selected Python package scope; check PyPI for publication
**Source:** planned `v0.2.10` tag
**Version DOI:** `10.5281/zenodo.23106744` (citable after Zenodo publication)

Version 0.2.10 selects a Python wheel and source distribution for a
release-specific citation once published. The earlier `v0.2.9` tag remains
a source-only snapshot; it was not a PyPI release.

## Distribution and verification

- The wheel and source distribution contain the selected installable sources
  and lightweight traceability records. The package and served documentation
  have separate frozen-scope public-content checks.
- The engineering and documentation CI checks apply to the release source
  revision. Installed-package probes check the produced distributions outside
  the repository checkout.
- The planned Zenodo record contains only the selected distribution files and
  their checksums. It does **not** include the entire GitHub repository archive.

## What has not changed

- The carried 0.2.8 element-analysis registry and separate workflow records
  keep their original bounded maturity and evidence identities. This package
  release does not promote WP14 or reclassify historical failures.
- The full-repository archive remains failed under G03 and is not a cleared
  release artifact. GitHub's automatic source ZIP/tarball must not be treated
  as equivalent to the audited Python source distribution.
- Mixed distributed PETSc/MPI remains `NOT_VALIDATED`; research and
  experimental routes remain within their documented limits. No universal
  solver, certification or production-safety claim is made.
