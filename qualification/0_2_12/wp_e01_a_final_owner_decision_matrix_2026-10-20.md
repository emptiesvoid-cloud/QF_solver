## Source compatibility and scientific limits

The source review found direct implementation gaps: current residual normalization uses a `1.0` force-unit floor; the Newton loop does not evaluate the state after correction 25; current line search checks residual-merit reduction without a verified directional derivative; endpoint completion uses a tolerance below `λ=1`; and checkpoint state has no E01-A attempt-intent/ledger subrecord. WP10 already provides transaction-attested accepted composites, deterministic state digests, v2 model/topology/identity checks, canonical metadata integrity and atomic replacement. The approved E01-A contract is **NOT_IMPLEMENTED** at those points. Independent derivative/route checks and end-to-end verification are **NOT_VERIFIED**. `J2_TANGENT_CONSISTENCY` remains **BLOCKED_PENDING_INDEPENDENT_EVIDENCE**.

The derivative formula assumes a differentiable residual on the tested branch. At nonsmooth transitions, no Armijo descent certificate is assumed. J2 tangent consistency remains `BLOCKED_PENDING_INDEPENDENT_EVIDENCE`; this proposal does not authorize J2 tangent-driven Full Newton claims. The approved residual criterion, 25-correction limit, `c1`, cutback factor, rejection budget and transaction invariants remain unchanged. No numerical V&V was performed.
