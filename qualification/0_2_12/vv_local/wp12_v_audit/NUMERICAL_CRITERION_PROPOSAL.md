# WP12-V: prospective criterion for assembled-stiffness symmetry

**Status:** proposed numerical acceptance rule; not approved as a qualification criterion.  This document is a read-only scientific audit of the archived WP12-U attempt and frozen source identities. It does not change solver or test code, and it does not promote the failed attempt.

## Question and evidence

The narrow question is whether a nonzero difference between stored global entries `K[i,j]` and `K[j,i]` is an arithmetic-sized assembly defect or evidence of a broken stiffness construction/scatter. It is distinct from whether the global stiffness agrees with the exact mathematical operator. A symmetric mathematical operator need not have bitwise-identical computed entries after two separate floating-point reductions.

## Prospective bound (for criterion design, not current acceptance)

Use binary64 unit roundoff `u = 2^-53` (the conventional `eps` is `2u`). For a floating-point path with `p` rounded additions and finite normal intermediates, round-to-nearest, and no overflow/underflow, define

`γ_p = p u / (1 - p u)`.

For each canonical global coordinate pair `(i,j)`, let the corresponding stored element contributions be `a_e` for `(i,j)` and `b_e` for `(j,i)`, across exactly the same contributor set. The mathematical local stiffness is symmetric. The local stored-kernel asymmetry allowance is `L_ij = Σ_e |a_e-b_e|`; for the current scalar/batch post-symmetrized matrices, `L_ij = 0` if the contributor mapping and finite-value premise are verified. If a future kernel no longer constructs mirrored entries identically, `L_ij` must be measured or bounded from that kernel; it must not be silently set to zero.

Let `m_ij` and `m_ji` be upper bounds on the numbers of contributions reduced into the two slots, `S_ij = Σ_e |a_e|` and `S_ji = Σ_e |b_e|`, and `p_ij`, `p_ji` the addition counts used in the bounds. A conservative componentwise criterion is:

`|Khat_ij - Khat_ji| ≤ L_ij + γ_(p_ij) S_ij + γ_(p_ji) S_ji`.

The derivation is the ordinary addition model `fl(x+y)=(x+y)(1+δ)`, `|δ|≤u` under the declared arithmetic assumptions. Expanding the reduction expresses each input multiplied by products of at most p factors `(1+δ)`; their departure from one is bounded by γ_p when pu<1. Summing the resulting absolute errors gives γ_p S for each orientation. The triangle inequality adds the two reduction errors and the exact discrepancy between their local sums, at most L. This is an upper bound, not a fitted tolerance.

For any binary reduction of `m` contributions, each consumed exactly once, there are `m-1` rounded additions regardless of the ordering or tree shape. Under the stated model, `γ_(m-1)` therefore bounds the sum error for any such reduction order. With the same `m` mirrored contributions, `S_ij=S_ji=S`, and `L=0`, the difference is bounded by `2 γ_(m-1) S`. A structural upper bound `M ≥ m` is also valid: use `γ_(M-1)` (monotone in `M` for `M u < 1`) and the `S` bound. Zero-valued structural contributions may be included in `M`; they do not invalidate the conservative bound if each matrix entry is consumed at most once. Runtime order is useful to attribute the observed final bit, but is not needed for this error bound. The selected SciPy path for this case is additionally characterized by sequential `sum_duplicates` after sorting, and its one-chunk `(14,22)` pair has `m=3`, so `p=2` applies. The corresponding numeric bound remains unevaluated because the archived receipt omits `S`.

### Inputs that a V2 diagnostic must expose

For every tested global pair (or enough data to reproducibly derive it without reassembling): canonical indices; an upper structural contribution count `M` (actual count is optional if every structural term is included exactly once in `M`); the post-kernel binary64 `a_e,b_e` values or their exact reproducible hashes plus verified recomputation inputs; `L_ij`, `S_ij`, and `S_ji` computed with a summation method whose own error is bounded (e.g. upward-rounded accumulation, or a separately documented enclosure); and the reduction family needed to justify the `m-1` addition model. Record dtype, IEEE rounding mode, and finite checks. The fixture topology's upper count is sufficient for a conservative `γ` factor; it cannot replace `S`, especially where signed stiffness terms cancel. If subnormal values or intermediates occur, either provide a compatible absolute-error model for those operations or classify the criterion as inconclusive under the normal-arithmetic profile. This is a limitation of the selected bound, not a universal scientific rejection of subnormal data.

## Near-zero, normwise and exact-symmetry guards

Do not divide by `max(|Kij|, tiny)` or add a fixed dimensional absolute floor: when the exact entry is zero or near zero, the relative ratio is unstable, while a floor can make a large error appear acceptable under unit rescaling. The elementwise absolute bound above is scale-aware through `S`; if `S=0`, `L=0`, and the reductions contain only exact zeros, the expected difference is exactly zero. If an independently computed exact rational reference is available, separately compare the computed matrix to that reference with both a declared normwise error and componentwise error bounds; symmetry alone cannot establish value accuracy. Preserve exact equality only as a construction invariant where the implementation explicitly mirrors one stored value into both slots, not as a universal property of an independently reduced assembled matrix. NaN/infinity or overflow-risk inputs should be refused or explicitly classified under a finite-arithmetic profile; subnormals require an applicable absolute bound or an inconclusive classification.

The infinity/relative-Frobenius exact-oracle check is a separate global-scale diagnostic. It may detect gross operator error but can hide an isolated near-zero component, and it is not interchangeable with `|Kij-Kji|` or the local contribution-sum bound. Neither this symmetry bound nor agreement with the exact assembled matrix proves that a separate matrix-free operator applies the same operator for all vectors. No arbitrary `atol`, `64 n u`, or unitless multiplier is endorsed here.

### Required negative controls for any future criterion implementation

Before a future criterion can be trusted, synthetic/unit-level checks must show: (1) exact mirrored finite contributions are accepted within the derived reduction bound; (2) perturb one mirrored contribution by more than its computed bound and ensure rejection; (3) include cancellation/zero-reference entries and verify there is no fixed-`atol` escape; (4) vary units by a power-of-two scale and confirm the bound scales with `S`; (5) alter a DOF mapping/contributor set while keeping a small normwise global error and ensure the structural/independent-oracle check detects it; and (6) inject NaN, infinity, subnormal, overflow/underflow-risk or unknown reduction behavior and require an explicit inconclusive/refusal classification. These are design requirements, not tests executed for this audit.
