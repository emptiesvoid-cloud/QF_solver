## Reference values

The historical H1/H2/H3 mean tip UZ values are `-5.14927314061041e-9 m`, `-1.67818184663409e-8 m` and `-4.795612893178559e-8 m`. The beam estimate is `-1.4397142857142855e-7 m`; the H3 difference is 66.69%. This is a one-dimensional Euler-Bernoulli/Timoshenko diagnostic, not an exact 3D reference. Its gap does not prove shear locking.
