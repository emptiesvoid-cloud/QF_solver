## Proposed acceptance checks

Use IEEE-754 binary64 unit roundoff `u=2^-53`, finite-value checks, and matrix/vector norms. Every criterion is conjunctive. Thresholds are prospective values for this fixed 2-DOF case and should be reviewed with the owner before registration.

**A — polynomial roots and conditioning record.** Retain the independent test's per-root criterion `|λᵢ-λᵢ*|/|λᵢ*| ≤ 1e-10`, with roots finite, ordered, and paired by ascending order. Its provenance is the [test assertion](../../../../tests/unit/test_modal_two_dof_independent_oracle.py#L59). WP04 separately records an eigensolver tolerance of the same numerical value; an algorithm setting does not itself guarantee this eigenvalue error. Since both exact roots are nonzero, do not introduce a max-scale denominator or dimensional absolute tolerance. Record the eigenvalue relative gap using the WP04 definition and confirm it exceeds the cluster threshold `1e-8`; this case gap is about `0.5841`. Do not impose an arbitrary conditioning cap or widen tolerance after seeing results. Report exact case conditioning so reviewers can judge sensitivity: raw 2-norm eigenvalues of M are `(7/4 ± √2/4)`, giving `κ₂(M)≈1.50636`; raw K eigenvalues are `(14 ± 2√10)`, giving `κ₂(K)≈2.647997`. For the WP04 diagonal congruence `D^-1/2 A D^-1/2`, eigenvalues are `1±1/(4√3)` for M and `1±1/(2√10)` for K, giving scaled condition numbers about `1.337` and `1.376`. These diagnostics describe this fixture; they do not justify a universal conditioning threshold.

**B — independent projection arithmetic and modal off-diagonal.** Compare the production reduced operator with an independently evaluated dense bilinear projection elementwise. For the stated operation `fl(φᵢᵀ fl(K φⱼ))`, under binary floating-point round-to-nearest, normal finite intermediate arithmetic without overflow/underflow, and the conventional length-n dot/matrix product error model, use `u=2^-53` (unit roundoff; binary64 machine epsilon is `2u`), `γₙ=(n*u)/(1-n*u)` with `n=2`, and the entrywise bound `Bᵢⱼ = γₙ(2+γₙ) |φᵢ|ᵀ |K| |φⱼ|`. This bounds one computed path against the exact bilinear scalar. For two computed paths, accept their absolute difference only if it is no greater than the sum of their respective bounds (each computed from that path's own vector/operator inputs). If the implementation's sparse product, loop accumulation, BLAS backend, rounding mode, or normal-arithmetic assumptions are not verified to satisfy this model, report the bound as a diagnostic proposal and do not treat it as an acceptance limit until the arithmetic path is characterized. Keep the existing WP04 relative Frobenius diagonalization check `||K_r-diag(λ)||_F / max(||K_r||_F,tiny) ≤ 1e-8`; it is distinct from this projection-vs-projection comparison. For the symmetric structured path, exact mirrored assignment is expected by construction; a tiny computed off-diagonal is not required to equal zero. Under exact algebra, `K_r,ij = λⱼ G_ij + φᵢᵀrⱼ`, where `G=ΦᵀMΦ` and `rⱼ=Kφⱼ-λⱼMφⱼ`. Thus modal residual and mass-Gram errors condition the off-diagonal, but are not equivalent to a direct projection comparison; arithmetic in the products and scalar accumulation adds its own rounding term. The archive did not expose actual modes, so the analytical vectors in the root-cause report cannot be substituted to claim that the archive's off-diagonal satisfies this bound. A future test should emit those vectors and elementwise bound inputs, or classify the projection-bound check as `NOT_EXPOSED`/diagnostic. No arbitrary `64 n u κ` or `8u` acceptance multiplier is asserted here.

**C — modal residual.** For each returned pair retain the WP04 definition `ρ_j=||Kφ_j-λ_jMφ_j||₂/(||Kφ_j||₂+|λ_j| ||Mφ_j||₂)`. Require finite, nonzero denominator and `ρ_j≤1e-8`, preserving the preregistered WP04 criterion. Record residuals separately by mode. This dimensionless check is backward-error-like; it does not bound physical truncation error or validate model adequacy. The archive reports approximately `1.01e-16` and `5.94e-17`.

**D — mass normalization / orthogonality.** Form the full Gram matrix `G=ΦᵀMΦ`; report its entries and require `||G-I||_F≤1e-8`, preserving the WP04 limit. Each diagonal modal mass is dimensionless and should be near one; off-diagonal Gram terms are dimensionless and test mutual M-orthogonality. Report each mode's pre-normalization generalized mass as positive/finite where accessible. Do not check only individual diagonal normalization: a corrupted pair can each have unit mass and still be nonorthogonal. The receipt reports Frobenius error `3.54e-16`.

**E — independent projection identity and exact-symmetry route.** Check production `K_r` against the independent dense `ΦᵀKΦ` using the elementwise two-path `γₙ` bounds in B when their arithmetic assumptions are verified; otherwise emit the comparison and bound diagnostics without claiming a pass. Compare `M_r` against independently formed `ΦᵀMΦ` with a scale-aware norm and explicit arithmetic model. Never use `rtol` alone against zero entries. Require exact mirrored equality only for the implementation’s structured reduced matrix, not equality to a zero off-diagonal. Confirm physical input K remains unchanged. The structured projection is mathematically equivalent for exactly symmetric K; it forces output symmetry through paired assignment. For nonexact but contract-tolerated symmetric K, the implementation preserves direct bilinear projection, which can have a small nonsymmetric component proportional to input asymmetry. Do not demand exact symmetric output there; assess it against the input symmetry defect and projected norm. A follow-up synthetic asymmetry branch should establish continuity and must not symmetrize/repair K as a test convenience.

For this tiny case, a preferable reference option is to evaluate the projection exactly over the binary64 values actually returned: convert each finite K/M/Φ entry with `Fraction.from_float`, then form the 2x2 bilinear sums using rational arithmetic. This gives an exact projection of the returned floating vectors, not exact eigenvectors. Only the production path's forward-error bound is then needed. Evaluate that bound with exact rationals or conservative outward rounding as well; an underestimated floating bound must not cause a spurious rejection. This option is a prospective test specification, not a computation performed on unavailable archived vectors.

## Error-detection and interpretation

The current archived assertion is defective because relative tolerance contributes nothing when the reference element is zero and `atol=0`. A change to fixed arbitrary `atol` would only conceal this mechanism. The elementwise bound in B accounts for matrix/vector magnitudes, floating-point unit roundoff, and dimension through `γₙ`; its assumptions are explicit, and it is not a universal condition-number multiplier. A deliberate fault injection (for example, add an off-diagonal perturbation larger than the computed elementwise two-path bound, or rotate one mode away from its eigenvector) should be used during test design to prove the respective B or C/D assertions fail. Keep fault injection separate from the scientific execution attempt and do not record it as solver evidence.

Use these outcome labels:

- `TEST_CRITERION_DEFECT`: oracle/assertion has a mathematically invalid or zero-scale comparison, while independent checks pass.
- `SOLVER_OR_PROJECTION_DEFECT_SUSPECTED`: a valid scale-aware root, residual, Gram, or projection criterion fails. Confirm via a separately controlled reproduction before assigning source cause.
- `CONDITIONING_LIMITED`: conditioning or spectral separation prevents interpreting the chosen accuracy claim; document the limitation instead of expanding tolerance after observation. No new condition-number cap is established here.
- `INCONCLUSIVE`: required observable or source identity is missing.
- `PYTEST_PASS_ONLY`: test process passed but scientific oracle adjudication is not yet made.
