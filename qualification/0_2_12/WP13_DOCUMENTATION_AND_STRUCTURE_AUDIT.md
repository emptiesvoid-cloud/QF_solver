# WP13 — audit de la documentation, de l’arborescence et de la cohérence scientifique

- Date de l’audit : 2026-11-01
- Dépôt : `emptiesvoid-cloud/QF_solver`
- Branche examinée : `codex/wp13-release-engineering-20261031`
HEAD de départ revérifié : `357b4b5398c1d3e5059e0a1049f8494f4096f13e`

## Portée et méthode

L’audit a porté sur le README, les métadonnées de distribution et de citation, les licences, le manifeste, les guides d’installation et d’utilisation, les références API, les pages de capacités, la documentation de vérification, les fichiers MkDocs, les exemples référencés, les notes de version et les rapports WP12/WP13 qui déterminent les limites publiques. Le code et les tests correspondants ont été consultés pour distinguer la présence d’une route de sa portée de preuve.

Les contrôles documentaires mesurés sont : 1340 fichiers suivis sous `docs/`; 55 entrées de navigation MkDocs, toutes résolues vers un fichier existant; build MkDocs strict réussi; 106 liens Markdown dans README, dont 90 cibles locales valides et 16 URL externes uniques retournant HTTP 200. Les ancres locales du README sont incluses dans le contrôle. Les URL publiques du site ont été vérifiées le 2026-11-01 : `/`, `/docs`, `/getting-started`, `/versions`, `/roadmap`, `/project`, `/capabilities` et `/docs/api` répondent.

Les contrôles n’impliquent ni déploiement du site ni validation de toute l’histoire Git. Le scan complet de dépôt demeure distinct du contrôle de la surface de distribution et G03 conserve son résultat indépendant.

## Décisions et risques résiduels

- La surface publique représente 0.2.11 comme version publiée. 0.2.12 reste une candidate sans date de sortie ni DOI de version.
- Le build MkDocs vérifie la cohérence de construction; il ne déploie pas le site et ne rend pas automatiquement chaque page historique visible dans le menu.
- Le nouveau contrat de package doit recalculer les identités pour README, `pyproject.toml`, `CITATION.cff` et la politique MkDocs modifiés. Les artefacts v6 restent historiques.
- G03 reste `FAIL_PRESERVED`; la revue juridique indépendante des dépendances demeure `NOT_ACQUIRED`.
- Les six smoke tests installés sont soumis à une approbation Owner exacte sur le nouveau manifeste et les nouveaux hashes. Aucun calcul n’est autorisé par ce rapport.
- Aucun seuil, oracle, résultat WP12, ledger ou maturité scientifique n’a été modifié.

## Verdict de l’audit

Les défauts documentaires P1 identifiés dans le périmètre ont reçu des corrections ciblées et leurs liens/constructions sont vérifiés. Les limites de qualification, l’échec G03 et les validations non acquises restent explicites. Cet audit n’autorise ni publication, ni fusion, ni tag, ni déploiement.
