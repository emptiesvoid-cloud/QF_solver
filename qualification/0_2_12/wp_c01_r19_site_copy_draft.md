# Draft copy for a later qfsolver.org update

> **Not published.** This text is for a future Owner-reviewed site update only.

QF Solver includes an experimental, bounded option for work-conjugate frictional contact transfer in a linear-static, small-rotation setting with one initially frozen slave/master pair and a triangular master face. It is explicitly opt-in; the legacy transfer remains the default. Exploratory R13/R14 checks observed stick and slip, and an offline replay of the integrated R16 archive reproduced nine accepted steps and an independently reconstructed raw moment below the existing 0.002 N·m check. This evidence does not qualify finite sliding, large rotations, multiple contact, a global consistent slip tangent, general mesh convergence, or production use. No numerical rotation cutoff is enforced.
